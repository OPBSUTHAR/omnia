Step by step

Installing Omnia.

01

Android

  1. Download omnia.apk.
  2. When Android asks, allow installs from your browser. This is a one-time permission.
  3. Open the downloaded file and tap Install.
  4. Later updates install over the app and keep your session, notes and settings.
02

Windows

  1. Download omnia-windows.exe.
  2. SmartScreen may appear because the build is unsigned. Choose More info → Run anyway.
  3. The installer creates Start menu and desktop shortcuts.
  4. Launch Omnia from the Start menu or desktop.
03

Linux

  1. Download omnia-linux.AppImage.
  2. Open a terminal in your Downloads folder.
  3. chmod +x omnia-linux.AppImage
  4. Double-click the file, or run ./omnia-linux.AppImage.
04

Web & iPhone

  1. Open the web app in Chrome, Edge, Firefox or Safari.
  2. On iPhone or iPad, tap the Share button in Safari.
  3. Choose Add to Home Screen.
  4. Omnia opens full-screen with its own icon.
What's inside

A real app, not a shortcut.

The same Expo + React Native codebase renders the phone app, the desktop app and the website. Layouts reflow from a 320 px phone to an ultrawide monitor.

  • Local-first sessions. A name, an emoji badge and a device ID stored only on your device. No account, no server, no tracking.
  • Three working tools. A focus timer, a converter and an autosaving scratchpad.
  • Live in-app updates. The app checks its release feed on launch, on foreground and every four minutes. A new build opens a real update dialog inside the app.
  • Light, dark and system themes. Applied instantly across every screen.
Updates

New builds arrive inside the app.

When a release is published, Omnia compares the feed version with the installed build and shows the release notes. Android downloads the next APK; Windows and Linux download the next installer; the web app reloads the newest deployment.

Why are the app and this guide on different hosts?

The actual app is a full React application deployed on Vercel at omnia-suthara.vercel.app. This GitHub Pages site is deliberately static: it stays available even if the app host is down, and it is the canonical place for install steps and download links.
