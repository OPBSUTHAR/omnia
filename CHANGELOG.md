# Changelog

All notable changes to Omnia are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[semantic versioning](https://semver.org/).

<!-- releases -->

## [1.1.0] - 2026-10-26

- Real Windows and Linux desktop installers built with Electron
- The full web app now runs on Vercel; GitHub Pages is the install guide
- Downloads live in the global app footer with direct links
- Update dialog selects the right installer for each platform
- Fixes for the desktop sidebar and mobile settings layout


## [1.0.0] - 2026-10-26

- First public build — Omnia now lives on Android, the web and your desktop.
- Local-first sessions with a name, a badge and a device identity.
- Three working tools: a focus timer, a unit converter and an autosaving scratchpad.
- Live update alerts: when a new build ships, Omnia tells you inside the app.
- Light, dark and system themes with a phone-to-desktop responsive layout.
