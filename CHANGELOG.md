# Changelog

All notable changes to Omnia are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[semantic versioning](https://semver.org/).

<!-- releases -->

## [1.4.1] - 2026-10-27

- Update all public links and download mirrors to the renamed orbisnova repository
- Feed and Pages mirror now resolve under OPBSUTHAR/orbisnova
- Same signing key, installs over 1.4.0 and preserves data


## [1.4.0] - 2026-10-27

- Add in-game Tetris with ghost, hold, scoring and levels
- Full touch controls for phone, arrow keys and Space on desktop
- Refresh the toolkit to five live utilities
- Same package, key and data preserved


## [1.3.0] - 2026-10-27

- Rebranded the app as OrbisNova with a new globe icon and refreshed interface.
- Added a universal calculator with basic and scientific modes, live results and history.
- Updated the website, docs and desktop installers with the OrbisNova identity.
- Kept the existing package and signing key, so this build updates over 1.2.1 and preserves your data.


## [1.2.1] - 2026-10-26

- Android updates now download inside Omnia with a live progress bar instead of opening a browser.
- When the APK is ready, Omnia opens Android's installer automatically; allow installs from Omnia the first time.
- Fixes the browser download that stopped at 100 percent and never returned to the app.
- Your session, scratchpad and settings are preserved.


## [1.2.0] - 2026-10-26

- Phone home stats now fit on one compact row instead of stacking into three sparse bars.
- Fixed the blank space after the focus timer on Android: the converter and scratchpad now render at their full height.
- Toolkit cards and tool panels no longer collapse on narrow phone screens.
- Cleared the Expo export cache so update checks always compare the real installed version.


## [1.1.0] - 2026-10-26

- Real Windows and Linux desktop installers built with Electron
- The full web app now runs on Vercel; GitHub Pages is the install guide
- Downloads live in the global app footer with direct links
- Update dialog selects the right installer for each platform
- Fixes for the desktop sidebar and mobile settings layout


## [1.0.0] - 2026-10-26

- First public build — Omnia now lives on Android, the web and your desktop.
- Local-first sessions with a name, a badge and a device identity.
- Three working tools: a focus timer, a unit converter and an autosaving scratchpad.
- Live update alerts: when a new build ships, Omnia tells you inside the app.
- Light, dark and system themes with a phone-to-desktop responsive layout.
